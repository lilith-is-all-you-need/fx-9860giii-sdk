Loader 下一阶段需求与验收基线 / 2026-11-18
状态：需求已对齐；本文描述目标，不代表新版运行功能已经交付。

1. 身份与目录
一个 Add-in 对应一个可整体复制的兼容目录，默认由名称＋短 hash 决定，不再按时间戳和随机号生成新身份。
完整 SHA-256 绑定镜像与 profile；短 hash 仅作名称，必须检测截断碰撞，绝不覆盖不同镜像。
同镜像重复导出应可复用或明确更新，不能静默清除运行记录；不同内容同名必须共存。
计算器采用短目录 ID，元数据保存完整人类名称与全 hash。官方界面的八字符/三级目录限制是保守可移植设计依据，不等于未经验证的 Bfile 底层长度结论。
公共 Loader 从约定程序根目录发现程序目录，不能仍要求唯一根目录 target.bin/Loader.idx。
库可直接接受程序目录路径；目录内路径受边界检查，版本/大小/哈希/能力不匹配要明确拒绝。
PC 分析报告保存在电脑；计算器只需镜像、运行 profile、图标/元数据和必要运行记录。

2. 解耦与界面
Profile Studio 默认只导出程序依赖目录；提供“同时导出 Loader”和独立“导出 Loader”入口。
已有程序无需重新分析即可取得正确版本 Loader。计算器界面英文，采用统一黑白像素图标、列表、状态、分页与明确按键提示。
电脑界面提供中文/英文切换；用户手册及踩坑手册各有中文/英文版。
PC 语言切换不改变已导出程序身份或 profile ABI。

3. 加载库
第一版只支持 A→B，拒绝 A→B→C；先检查调用层数再修改映射、释放资源或保存文件。
正常目标退出必须恢复调用方；不能把返回 OS 当作完成此项。
宿主允许配套暂停/恢复接口、业务状态保存/恢复接口，以及 RAM 不足时的临时存储。
需要明确运行时持有的内存、堆、栈、页表、缓存、驱动、VBR、定时器及回调所有权；不能只备份一个 RAM 字或几个寄存器。
MENU 后直接选回 A：调用方可选择结束 B、恢复 A，或继续 B、待 B 退出再恢复 A。
开始运行其他 OS 应用可以结束旧会话。目标崩溃或 OS 重启后不要求恢复。
若 OS 正常把 A 当新启动，允许重新初始化并读取宿主业务状态；不承诺旧栈、指针、文件句柄继续有效。
无法暂停/恢复的目标组合应在可判定时拒绝，未知风险明确呈现。库化不是任意程序透明进程虚拟化保证。

4. 超限运行库
主要面向可修改源码的项目。提供构建/链接与入口接入、页表/缺页处理、常驻区域、OS 切换和资源约束。
数学库、Giac 私有 arena 和具体 UI 保持应用层，通用补页机制移入可复用库。
边界覆盖第 512/513 页、跨页取指和读取、部分尾页、更新/失效映射以及异常上下文禁止 Bfile。
现有 699 页 Giac 是实例，不是唯一接口定义，也不是所有超限 G1A 已兼容的证据。

5. 速度
用户观察是启动慢、启动后运行似乎正常，原 G1A 秒开；没有已测定的启动时长。
先为准备/验证/日志/查页/影子页/按键释放/交接计时，计数保存在 RAM、集中写回，避免计时本身增加文件操作。
保留完整检查默认模式，并提供显式快速模式：首次完整检查，后续可不做全文件校验。
快速模式不能承诺发现同大小、同地址的内容更改；仍须查询真实页地址、检查元数据、范围和运行库契约。物理地址不能长期缓存为正确性依据。
profile、运行库或输入可观测信息变化应使快速缓存失效，并提供强制完整检查。
任何提速数字必须用同镜像、同一台机器、同一时钟设定对照。不能用模拟器指令数宣称实机秒数。

6. SH3
目标是在 GIII 上运行旧 SH3 Add-in，不另做 SH3 实机 Loader。
优先共用 GIII 执行后端，PC 识别已知旧硬件例程并生成精确补丁证据；不做全局地址差分。
ISA 向上兼容不等于键盘、计时器、灰阶、LCD、OS 内部地址和 VBR/MMU 兼容。
未知硬件依赖不自动认定安全；候选、已匹配适配、未解析依赖分别记录。

7. 验收
多个目录同时安装并选择正确程序；重复导出、重名、短 hash 碰撞及目录移动不能混用 profile。
A 保存静态变量/堆对象/界面与业务状态 → B 交互 → 正常退出恢复 A；失败与取消不破坏 A。
分别验证 MENU 两策略，测试实体 MENU，不以注入按键替代。
通过官方 SDK 风格及 gint 宿主样例证明接口，覆盖分配失败、文件空间不足、缓存失效、坏 profile/日志和状态保存中断。
完成上述证据前不把“导出静态库成功”写为“可保留调用者状态”。

工作区资料：inventory.json 为证据目录；sh3/ 为中英 SH3 研究；SDK手册另按有效证据精选。
