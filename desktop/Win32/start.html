Fx Studio Win32

fx-9860GIII · C / C++ 开发工作台

编译并运行第一个工程

  1. 完整解压压缩包，双击顶层的 FxStudio.Win32.exe。
  2. 点击 打开计数器示例。工作台会创建可编辑的 C++ 副本。需要 C 或有界内存模板时，选择 文件 → 新建工程。
  3. 按 Ctrl + Shift + B 构建。安装目录含中文时，首次构建会准备工具链缓存，可在输出窗查看进度。按 F5 启动调试，程序会停在 main。再次按 F5 继续运行，点击右侧计算器的 + 可看到计数增加。
  4. 在 change_counter 的可执行行左侧单击添加断点，再次点击计算器的 +。暂停后，底部可查看变量、栈帧、寄存器、内存与反汇编。
  5. 按 Shift + F5 停止，切换 Release 后构建。选择 文件 → 导出已校验 G1A，将导出的 G1A 复制到计算器。

常用入口

任务操作
已有工程或调试包打开或拖入工程目录、CMakeLists.txt、*.fxide.json 或 *.fxdebug.json。预编译调试包的源码以只读方式打开。
编辑与检查工程树双击打开文件或预览图片，右键目录新建源文件。Ctrl+F 查找，F3 查找下一个。导入资源后自动生成声明和构建规则。
调试与屏幕F9 切换断点，F10 逐过程，F11 逐语句，Shift+F11 跳出。选择底部的断点或监视标签可修改条件和数值。右侧支持长按按键、整数倍屏幕预览和原始 128 × 64 PNG 导出。
旧 fxlib 与资源在工具菜单迁移旧目录，或导入 bitmap、image、binary 和 font。旧工程原件保存在原目录。
Loader 与资料工具 → FX Profile Studio 打开批量生成器，也可单独导出 Loader。帮助 → 计算器资料库 可按主题、地址或系统调用搜索。
脚本与自动化Studio/FxStudio.Agent.exe --stdio 提供原 SDK 的本地接口。随包示例、脚手架和工具分别位于 Studio/examples、Studio/scaffolds 和 Studio/tooling。

更多设置与原开发环境见 SDK 中文手册。完整操作表、依赖版本与重建命令见 Win32 源码说明。

English quick start

Extract the entire archive and launch FxStudio.Win32.exe. Switch to English under 工具 → Language / 语言. Open the counter example, build with Ctrl+Shift+B, and press F5 twice to run it. Click the calculator’s + key. Use the File menu to export a verified Release G1A. The SDK, debugger and emulator are bundled. Read the SDK guide.
